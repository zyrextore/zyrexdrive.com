# ZYREX Drive — Phase 5

## Garage & vehicle customization
- Expanded the existing garage without replacing the Phase 4 driving loop.
- Added per-vehicle saved settings for paint, ride height, camber, engine tune, wheel style, headlights, exhaust style, and brake bias.
- Added rendered wheel-style overlays for Sport / Deep Dish / Mesh while preserving the source GLB wheel meshes.
- Added vehicle headlight objects with Auto / Always On / Off behavior.
- Added exhaust-tip geometry and performance/titanium visual variants.
- Brake bias now affects braking strength in the driving physics.
- Existing GLB loading, wheel animation, suspension, body roll, camera, mobile controls, and procedural audio remain active.

## Integrity / limitations
- No RBXM-to-browser conversion is claimed.
- No new external model pack is fabricated; the added garage parts are procedural Three.js geometry attached at runtime.
- Browser WebGL/CDN runtime is not claimed as fully tested in this environment.
