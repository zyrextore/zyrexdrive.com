# ZYREX DRIVE — PHASE 31–50

This release builds on Phase 30 without removing the existing website or game systems.

## Phase 31–40
- Vehicle dynamics assists: traction, TCS, ABS settings, drive modes.
- Fuel consumption and SPBU refuel flow.
- Advanced vehicle setup: traction multiplier, tire-size multiplier, suspension presets.
- Character outfit profile field.
- City districts and additional lightweight landmarks.
- Traffic density control.
- Storm/rain toggle.
- Expanded missions: Taxi Pasar, Night Run, Fuel Run.
- Local challenge modes: Speed Trial and Distance Trial.
- Reputation progression.

## Phase 41–50
- Multi-slot local saves (3 slots).
- Profile JSON export.
- Expanded systems panel and HUD.
- Tutorial/help overlay.
- Persistent Phase 31–50 settings in localStorage.
- Fuel, drive mode, reputation and challenge status HUD.
- Final systems dashboard integrating vehicle/city/missions/profile controls.

## Controls
- E: enter/exit/interact
- H: Phase 31–50 systems panel
- L: refuel when near SPBU
- B: cycle drive mode
- G: GPS
- P: race
- T: day/night
- Y: rain/clear
- N: nitro
- R: reset

## Validation
- Node syntax checks performed for game.js, server.js and script.js.
- ZIP integrity checked after packaging.
- Full browser/WebGL runtime is not claimed as verified in this environment.
