# ZYREX DRIVE — PHASE 20

## Main Menu + Player Character

Added without replacing the existing ZYREX website/game systems:
- Main menu overlay with Play, Garage, Missions, and Character actions.
- Game starts paused behind the menu so keyboard/controller input cannot move the vehicle until Play.
- Lightweight procedural player avatar visible in the 3D scene during menu/character preview.
- Character profile: display name, shirt/jacket color, pants color, hair color.
- Character settings persist inside the existing local ZYREX Drive profile.
- Menu HUD shows current progression level and wallet balance.
- Enter starts the game from the main menu.
- Escape returns to the main menu.
- Existing vehicle, garage, missions, race, traffic, weather, audio, controls, economy, dealership, GPS and graphics systems are retained.
