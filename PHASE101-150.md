# ZYREX PHASE 101–150

## 101–110 — Real-time transport
- Added Node HTTP server + `ws` WebSocket server at `/ws`.
- Browser authenticates the socket with the existing 7-day account token after connection.
- Room state, player transform, ready state and chat can travel over WebSocket.
- HTTP polling remains as an automatic fallback when WebSocket is unavailable.
- Reconnect backoff is built into the client.

## 111–120 — Online race session foundation
- Host can request an online race from the multiplayer room.
- Server validates host permission, minimum player count and ready state.
- Server creates a race session ID and synchronized `startAt` timestamp.
- Finish times are range-checked and each player can finish only once.
- This is server-validated session state, not authoritative vehicle physics yet.

## 121–130 — Party/lobby improvements
- Existing room model remains compatible with the new transport.
- Player presence, host handoff, ready state and room chat continue to work.
- WebSocket state updates reduce the need for repeated full room polling.

## 131–140 — Shared-world sync
- Remote vehicle transforms are broadcast to room peers.
- Client interpolation keeps remote vehicles visually smooth between network updates.
- Vehicle ID, color, heading and speed are synchronized.

## 141–145 — Validation / abuse resistance
- Server clamps world X/Z, heading and speed ranges.
- Transform updates are rate limited.
- Chat remains sanitized and length limited.
- Race finish values are validated server-side.

## 146–150 — Reconnect / performance / QA
- WebSocket disconnects show reconnecting state and retry automatically.
- HTTP fallback preserves multiplayer access if the socket cannot be established.
- Existing local save, account, leaderboard and game systems are preserved.
- Static Node syntax validation completed.

### Important limitation
Full browser WebSocket/WebGL runtime could not be executed in this build environment. `npm install --package-lock-only` also timed out, so the new `ws` dependency is declared in `package.json` but was not installed locally here. Do not treat this package as a completed browser/network runtime certification.
